# AI Agent Guidelines

This file contains strict instructions for any AI agent or assistant working on the Phomouse project.

## General Rule
- **APPEND ONLY:** You must ONLY add new information to this project's documentation or version logs when requested. 
- **NO DELETION:** Do not delete or overwrite existing history in `version_log.md` unless explicitly instructed by the user for a specific correction.
- **NO MODIFICATION:** Do not modify previous version entries. Each update should be a new entry or an addition to the current development version.

## Documentation Standards
- Always ensure `IMPROVEMENTS.md` matches the current state of the codebase after any feature change.
- Update `version_log.md` with every significant logic change, following the [Added, Changed, Removed, Fixed] format.
- If you introduce a new system or logic flow, explain it clearly in `IMPROVEMENTS.md`.
